## Before saving each screenshot, check for

- **Email addresses.** Hide or blur your own address. That includes Outlook acknowledgement emails, the account picker and the profile icon, and the "Responders' email" field in run details.
- **Your name and photo** in the top-right corner of Microsoft 365. Crop it out.
- **Connection details.** Collapse any "Connections" panel and don't capture connection names that include your address.
- **URLs.** Don't include the browser address bar. Form, flow and file URLs contain tenant and object IDs.
- **The form share link or QR code.** Don't capture these.

Crop to the relevant area. PNG files under about 500 KB each are plenty.
